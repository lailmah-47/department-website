Our Courses

Explore our comprehensive curriculum designed to build your computing skills

Introductory Courses

Introduction to Computer Science

CS 101

Fundamentals of programming, algorithms, and computational thinking. Covers problem-solving techniques and basic data structures.

Credits: 3 | Semester: Fall & Spring

Web Development Basics

CS 110

Introduction to HTML, CSS, and JavaScript. Learn to build responsive, interactive websites from the ground up.

Credits: 3 | Semester: Fall & Spring

Data Structures

CS 120

Study arrays, linked lists, stacks, queues, trees, and graphs. Understand their applications and performance analysis.

Credits: 4 | Semester: Fall & Spring

Digital Logic and Organization

CS 130

Boolean algebra, logic gates, digital circuits, and computer architecture. Foundation for understanding hardware systems.

Credits: 4 | Semester: Spring

Core Courses

Algorithms

CS 201

Design and analysis of algorithms. Covers sorting, searching, dynamic programming, and graph algorithms with complexity analysis.

Credits: 4 | Semester: Fall

Database Systems

CS 210

Relational databases, SQL, transaction management, indexing, and normalization. Hands-on experience with modern database systems.

Credits: 3 | Semester: Spring

Operating Systems

CS 220

Process management, memory management, file systems, and concurrency. Understand how operating systems work at a fundamental level.

Credits: 4 | Semester: Fall

Computer Networks

CS 230

Network protocols, TCP/IP, socket programming, and network security. Build and understand communication systems.

Credits: 3 | Semester: Spring

Software Engineering

CS 240

Software design patterns, development methodologies, testing strategies, and project management. Create professional-grade software.

Credits: 3 | Semester: Fall

Artificial Intelligence

CS 250

AI fundamentals including search algorithms, knowledge representation, and machine learning basics. Introduction to intelligent systems.

Credits: 3 | Semester: Spring

Advanced Courses

Machine Learning

CS 301

Supervised and unsupervised learning algorithms, neural networks, and deep learning. Practical applications in real-world problems.

Credits: 4 | Semester: Fall

Cybersecurity

CS 310

Cryptography, authentication, network security, and penetration testing. Learn to protect systems from threats.

Credits: 3 | Semester: Spring

Cloud Computing

CS 320

Cloud architectures, virtualization, containerization, and serverless computing. Deploy and manage applications in the cloud.

Credits: 3 | Semester: Fall

Distributed Systems

CS 330

Consensus algorithms, fault tolerance, and scalability. Design and implement systems that work across multiple machines.

Credits: 4 | Semester: Spring

Natural Language Processing

CS 340

Text processing, language models, and semantic analysis. Build systems that understand and generate human language.

Credits: 3 | Semester: Fall

Computer Vision

CS 350

Image processing, object detection, and visual recognition. Apply deep learning to solve vision problems.

Credits: 3 | Semester: Spring

Elective Courses

Game Development

CS 401

Game engines, graphics programming, and game design. Create interactive games and learn real-time rendering.

Credits: 3 | Semester: Spring

Mobile App Development

CS 410

Develop native and cross-platform mobile applications. Learn iOS and Android development frameworks.

Credits: 3 | Semester: Fall

Blockchain Technology

CS 420

Cryptocurrency, smart contracts, and distributed ledgers. Understand decentralized systems and their applications.

Credits: 3 | Semester: Spring
